# HorseRacing — WIN5支援ツール

netkeiba.com からWIN5対象レースの情報を自動取得し、Excelの検討シートを作成するツール集です。
専用の操作画面(ブラウザ)が付いているので、コマンド操作なしで使えます。

## 収録ツール

| ツール | 内容 | 出力先 |
|---|---|---|
| ① 軸馬決定シート作成 | 出走馬の過去5走成績＋単勝オッズを取得し、軸馬検討用Excelを作成 | `main-horse/output/` |
| ② WIN5出馬表エクスポート | 対象5レースの出馬表＋単勝オッズを取得し、オッズ検討用Excelを作成 | `win5_cards_export/output/` |
| ランチャー | 上記2つをボタンで実行できるブラウザ画面 | — |

---

## 使い方(クイックスタート)

1. **`WIN5支援ツール起動.bat` をダブルクリック**する
2. ブラウザに「WIN5 支援ツール」の画面が自動で開く
3. **対象日を選ぶ**
   - 土曜日のWIN5 → 「土曜日 (idx=0)」
   - 日曜日のWIN5 → 「日曜日 (idx=1)」
   - 祝日開催など → 「祝日」を選び、idx欄に数値を入力(通常は2)
4. **実行したいボタンを押す**(①または②)
5. 実行ログに進捗が流れ、「✅ 正常に完了しました」と出たら完成
6. **「出力フォルダを開く」**ボタンで、できあがったExcelの場所が開く
7. 使い終わったら**「終了」ボタン**を押してからタブを閉じる

> 💡 `launcher.py` を直接ダブルクリックしても起動しません(このPCでは.pyファイルの関連付けが無いため)。必ず `.bat` から起動してください。

## 知っておくと便利な仕様

### オッズについて
- **馬券発売前**に実行した場合は、netkeibaの**予想オッズ**が入ります(①のログには「発売前のため予想オッズを使用します」と表示)
- 発売開始後に実行し直すと**実オッズ**に置き換わります
- おすすめは**レース前日の夜〜当日朝の再実行**です

### 馬番(枠順)について
- JRAの枠順確定は概ね「土曜レース→金曜日、日曜レース→土曜日、重賞→木曜日」です
- **枠順確定前**に実行すると馬番列は空欄になります(オッズ・馬名などは人気順に入ります)
- 枠順確定後に再実行すれば馬番も埋まります

### 処理時間の目安
- 通常は**数秒**で完了します
- ページ構造の変化などで通常取得に失敗した場合のみ、自動でブラウザ描画(Selenium)に切り替わり数十秒かかることがあります

## セットアップ(新しいPCで使う場合)

1. [Python](https://www.python.org/downloads/)(3.11以上、動作確認は3.13)をインストール
   - インストール時に「Add python.exe to PATH」に必ずチェックを入れる
2. コマンドプロンプトで依存パッケージをインストール:

```
pip install requests beautifulsoup4 chardet pandas lxml openpyxl selenium webdriver-manager
```

3. このフォルダ一式を任意の場所にコピーし、`WIN5支援ツール起動.bat` をダブルクリック

※ selenium / webdriver-manager はフォールバック用です。Google Chromeが入っていれば自動でドライバを取得します。

## フォルダ構成

```
HorseRacing/
├── WIN5支援ツール起動.bat        ← これをダブルクリックして起動
├── launcher.py                   ← ランチャー本体(ブラウザ画面)
├── main-horse/
│   ├── main_horse_decide.py          ① 軸馬決定スクリプト
│   ├── main_horse_decide_sheets.xlsx   テンプレート(必須)
│   └── output/                        出力先
└── win5_cards_export/
    ├── win5_cards_export.py          ② 出馬表エクスポートスクリプト
    ├── race_cards.xlsx                 テンプレート(必須)
    └── output/                        出力先
```

各スクリプトの詳細仕様は `main-horse/README.md` / `win5_cards_export/README.md` を参照してください。

## コマンドラインでの実行(上級者向け)

ランチャーを使わず個別に実行することもできます。

```
# ランチャー(ブラウザ画面)を起動
python launcher.py

# 個別実行(対象日は環境変数 WIN5_IDX で指定。未指定時は各スクリプトの既定値)
set WIN5_IDX=0
python win5_cards_export\win5_cards_export.py
python main-horse\main_horse_decide.py
```

`WIN5_IDX` は netkeiba のWIN5ページの `idx` パラメータで、0=開催1日目(土曜)、1=開催2日目(日曜)です。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| batを押しても画面が開かない | Pythonがインストールされているか、PATHが通っているか確認(`python --version`) |
| 「対象レースを取得できませんでした」 | WIN5開催日の選択(土/日/祝)が正しいか、ネット接続を確認 |
| 「テンプレートExcelが見つかりません」 | `race_cards.xlsx` / `main_horse_decide_sheets.xlsx` が各スクリプトと同じフォルダにあるか確認 |
| オッズ列が空 | 発売前＋予想オッズも未公開の可能性。時間をおいて再実行 |
| 馬番列が空 | 枠順確定前です。確定後(前日夕方以降)に再実行 |
| 画面を閉じたのにプロセスが残る | 画面の「終了」ボタンで終了する。残った場合はタスクマネージャーで `pythonw` を終了 |
